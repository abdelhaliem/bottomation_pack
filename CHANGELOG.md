## 0.0.1

* Initial release of **Bottomation**!
* Added `Bottomation.delete(...)` and `AnimatedDeleteButton`.
* Letter suction micro-interaction along Bézier trajectory curves.
* Rotating hinge trash can lid physics.
* Pill-to-circle morphing container animation.
* Circular progress indicator arc with customizable sweep.
* Success state with dynamic checkmark path drawing and elastic spring animation.
* Preset styles: `DeleteButtonStyle.dark()` and `DeleteButtonStyle.purple()`.
* Added `AnimatedDeleteButtonController` for programmatic control and state observation.
* Added standalone `example/` application demonstrating interactive features and presets.
